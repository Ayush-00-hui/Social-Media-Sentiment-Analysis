STEP 2: DOCKER COMPOSE ORCHESTRATION & DATABASE INITIALIZATION
================================================================================

Where to run: Inside `/projects/social-media-sentiment` directory on Home PC.

Grouped Command Block #2:
```bash
# Build Docker images and start all services in detached mode
docker-compose -f docker/docker-compose.yml up --build -d

# Check status of running containers
docker-compose -f docker/docker-compose.yml ps

# Inspect logs to verify PostgreSQL schema initialization
docker-compose -f docker/docker-compose.yml logs postgres-db
```

Configuration Line Verification (`docker/docker-compose.yml`):
Ensure the following ports and volume mounts are configured:
  - Line 11: `3000:3000` (Main Web Dashboard & Express/FastAPI API)
  - Line 24: `5432:5432` (PostgreSQL Database)
  - Line 27: `../database/schema.sql:/docker-entrypoint-initdb.d/schema.sql` (Auto-creates tables)
